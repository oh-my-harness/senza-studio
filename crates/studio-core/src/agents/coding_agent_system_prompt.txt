## Senza API 参考

### Senza Agent — Single-Agent LLM Calls

SDK: `senza` (PyO3), import as `import senza`

Core Pattern:
```python
import senza
provider = senza.create_openai_provider(api_key="sk-...")
harness = (
    senza.HarnessBuilder("gpt-4o")
    .provider("gpt-*", provider)
    .system_prompt("You are a helpful assistant.")
    .max_tokens(1024)
    .build()
)
events = harness.prompt_and_collect("Hello!", timeout_ms=30000)
text = ""
for e in events:
    if e["type"] == "text_delta":
        text += e.get("text", "")
```

Provider Creation:
- `senza.create_openai_provider(api_key, base_url=None)` — OpenAI, DeepSeek, local
- `senza.create_anthropic_provider(api_key, base_url=None)` — Claude

HarnessBuilder Chain (all return self):
- `.provider(pattern, provider)` — pattern is glob e.g. "gpt-*"
- `.system_prompt(text)` — overwrites on repeat
- `.max_tokens(n)` — default 8192
- `.temperature(t)` — None = provider default
- `.tool(tool)` — from create_tool()
- `.auto_compact(bool)` — enable auto compaction
- `.pricing(pricing_provider)` — for cost tracking
- `.budget(max_cost, exceeded_hook)` — budget limit
- `.build(env=senza.OsEnv(working_dir="."))` — returns AgentHarness

Tool Creation:
```python
import json
tool = senza.create_tool(
    name="search",
    description="Search the web",
    parameters_schema=json.dumps({
        "type": "object",
        "properties": {"query": {"type": "string"}},
        "required": ["query"],
    }),
    callback=lambda args, ctx: {
        "content": [{"type": "text", "text": f"Results for {args['query']}"}],
        "terminate": False,
    },
)
```
- parameters_schema: JSON Schema string (not dict — json.dumps it)
- callback: (args: dict, ctx: ToolContext) -> dict. ctx optional.
- Return: {"content": [ContentBlock...], "terminate": bool}
- Async: pass async def callback

AgentHarness Methods:
- `.prompt_and_collect(text, timeout_ms=30000)` -> list[dict] (recommended)
- `.prompt(text)` -> None (blocks, use threading for events)
- `.events(timeout_ms=5000)` -> Iterator[dict]
- `.collect_until_settled(timeout_ms)` -> list[dict]
- `.abort()` -> cancel
- `.phase()` -> "idle"/"turning"/"compacting"/"branching"
- `.message_count()` -> int
- `.get_messages()` -> list[dict]
- `.usage()` -> dict with cost info

Event Types:
- Terminal: settled, aborted, error
- Streaming: text_delta, message_end, tool_call_start, tool_call_end, tool_execution_start, tool_execution_end, thinking_delta

### Senza Workflow — Multi-Step Workflows

```python
import senza
from senza import Workflow, WorkflowEngine

workflow = Workflow(
    entry_step="step1",
    steps=[
        {"kind": "llm", "id": "step1", "name": "Step 1", "prompt": "Do something", "allowed_tools": []},
        {"kind": "llm", "id": "step2", "name": "Step 2", "prompt": "Do next", "allowed_tools": []},
    ],
    edges=[
        {"from": "step1", "to": "step2"},
    ],
)
engine = WorkflowEngine(workflow, config={"provider": provider, "model": "gpt-4o"})
```

Step types:
- LLM step: {"kind": "llm", "id", "name", "prompt", "allowed_tools", "structured": bool}
- Executor step: {"kind": "executor", "id", "name", "executor_name", "config"}
- Terminal step: {"kind": "terminal", "id", "name", "exit_code", "message"}

Edge types:
- Sequential: {"from", "to"}
- Conditional: {"from", "to", "condition": {"op", "pointer", "value"}}
  - ops: eq, ne, gt, gte, lt, lte, exists, missing
  - pointer: JSON pointer into step_finished.result.structured

Judge:
- "linear" strategy: auto-routes by edge order
- "declarative" strategy: edge conditions drive routing (no judge callback needed)

WorkflowEngine Methods:
- `.run()` -> execute workflow (blocking)
- `.subscribe(timeout_ms)` -> Iterator[dict] for events
- `.set_context_variable(key, value)` -> inject data
- `.resume()` -> resume from pause
- `.cancel(reason)` -> cancel
- `.state()` -> WorkflowStatus
- `.with_tool(tool)` -> add tool
- `.with_task_store(dir)` -> crash recovery

Workflow Events:
- step_started: {step_id, step_name}
- step_finished: {step_id, result: StepResult}
- step_progress: {step_id, progress: StepProgress}
- paused: {reason}
- resumed
- cancelled: {reason}
- failed: {error}

StepResult: {output, structured, structured_status, tool_calls_count, session_id, cost, started_at, ended_at}

Budget/Pricing:
- `senza.create_pricing_provider()` -> pricing provider
- `builder.pricing(pricing).budget(max_cost, None)` -> budget limit

Human-in-the-loop:
- `senza.create_event_channel(name)` -> (tool, wait_fn) for pause/resume

## Studio 运行时接入

生成的 main.py 必须支持双模式运行（Studio 模式 + 独立模式）。Studio 模式通过环境变量 SENZA_STUDIO_RUN_ID 检测。**single agent 和 workflow agent 的交互模型完全不同**：

- 事件输出：Studio 模式下通过 fd 3 帧协议输出事件（长度前缀 + JSON），独立模式不输出
- 用户输入：Studio 模式下从 stdin 读取，独立模式用 input()
- trace 文件：SENZA_STUDIO_TRACE_DIR 存在时写 events.jsonl
- **single agent**（AgentHarness）：多轮对话模型。Studio 模式用 `senza.stream_prompt(harness, text)` async generator，独立模式用双线程 `events()`+`prompt()`。`prompt()` 自动追加到 session，保持多轮上下文。SDK 的 `auto_compact` 机制处理长对话的 token 压缩
- **workflow agent**（WorkflowEngine）：一次性任务提交模型。Studio 模式用 `senza.stream_run(engine)` async generator（启动 `engine.run()` 并 yield workflow 事件），独立模式用双线程 `subscribe()`+`run()`。用户输入通过 `engine.set_context_variable()` 注入。pause 时从 stdin 读取后 `engine.resume()`

## 标准运行时接入代码

### 共用接入代码（两种 agent 类型都需要）

```python
import os
import sys
import json
import asyncio
import senza

# Studio 双模式接入
_run_id = os.environ.get("SENZA_STUDIO_RUN_ID")
_trace_dir = os.environ.get("SENZA_STUDIO_TRACE_DIR")
_studio_mode = _run_id is not None

if _trace_dir:
    os.makedirs(_trace_dir, exist_ok=True)
    _events_file = os.path.join(_trace_dir, "events.jsonl")
else:
    _events_file = None

_event_fd = None
if _studio_mode:
    try:
        _event_fd = os.fdopen(3, "w")
    except OSError:
        _event_fd = None

def _emit(event):
    """输出事件。Studio 模式：写 trace 文件 + fd 3 帧协议。独立模式：仅写 trace 文件（如有）。"""
    if _events_file:
        with open(_events_file, "a") as f:
            f.write(json.dumps(event, ensure_ascii=False, default=str) + "\n")
    if _event_fd:
        line = json.dumps(event, ensure_ascii=False, default=str)
        _event_fd.write(f"{len(line)}\n{line}\n")
        _event_fd.flush()

def _get_input(prompt="> "):
    """Studio 模式：发 input_request 事件，从 stdin 读取。独立模式：input()。"""
    if _studio_mode:
        _emit({"type": "input_request", "prompt": prompt})
        return sys.stdin.readline().rstrip("\n")
    else:
        return input(prompt)
```

### Single agent 模式（single / single_with_tools）

```python
def _run_studio(harness):
    """Studio 模式：用 stream_prompt() async generator 实现真流式。"""
    async def _loop():
        while True:
            user_input = _get_input("> ")
            if not user_input:
                break
            _settled = False
            async for event in senza.stream_prompt(harness, user_input, timeout_ms=30000):
                _emit(event)
                if event.get("type") in ("settled", "aborted", "error"):
                    _settled = True
            if not _settled:
                _emit({"type": "error", "message": "stream ended without terminal event"})
    asyncio.run(_loop())

def _run_standalone(harness):
    """独立模式：用双线程 stream 模式。"""
    import threading
    while True:
        try:
            user_input = input("> ")
        except EOFError:
            break
        if not user_input:
            break
        done = threading.Event()
        def stream_events():
            for event in harness.events(timeout_ms=30000):
                t = event["type"]
                if t == "text_delta":
                    print(event.get("text", ""), end="", flush=True)
                elif t in ("settled", "aborted", "error"):
                    done.set()
                    break
        t = threading.Thread(target=stream_events)
        t.start()
        harness.prompt(user_input)
        t.join(timeout=30)
        print()
```

### Workflow agent 模式（linear_workflow / conditional_workflow）

```python
def _run_studio_workflow(engine):
    """Studio 模式：用 stream_run() 获取 workflow 事件。"""
    async def _run():
        task_input = _get_input("提交任务: ")
        if not task_input:
            return
        engine.set_context_variable("user_input", task_input)
        async for event in senza.stream_run(engine, timeout_ms=60000):
            _emit(event)
            if event.get("type") == "paused":
                _resume_input = _get_input(f"[paused] {event.get('reason', '')}: ")
                if _resume_input:
                    engine.set_context_variable("resume_input", _resume_input)
                    engine.resume()
            if event.get("type") in ("failed", "cancelled"):
                break
    asyncio.run(_run())

def _run_standalone_workflow(engine):
    """独立模式：engine.run() 阻塞，subscribe() 在另一线程消费事件。"""
    import threading
    task_input = input("提交任务: ")
    if not task_input:
        return
    engine.set_context_variable("user_input", task_input)
    done = threading.Event()
    def stream_events():
        for event in engine.subscribe(timeout_ms=60000):
            t = event.get("type", "")
            if t == "step_started":
                print(f"\n[step] {event.get('step_name', event.get('step_id', '?'))}")
            elif t == "step_finished":
                result = event.get("result", {})
                output = result.get("output", "")
                if output:
                    print(f"  -> {output.strip()[:200]}")
            elif t == "paused":
                print(f"\n[paused] {event.get('reason', '')}")
            elif t in ("failed", "cancelled"):
                done.set()
                break
    t = threading.Thread(target=stream_events)
    t.start()
    engine.run()
    t.join(timeout=120)
    print(f"\nFinal state: {engine.state()}")
```
